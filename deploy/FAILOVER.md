# 联网问答主备部署（2026-09-04）

主用：Tavily basic → 硅基流动 zai-org/GLM-5.2，enable_thinking=false。
备用：智谱 search_std → 智谱官方 glm-5.1，thinking.type=disabled。
这是用户自己的智谱API，不是小智官方知识库。私人论文检索路由及向量模型不变。

主链路任一环节出现HTTP错误（包括认证、限流、余额等）、网络异常、空搜索结果、空/截断模型输出、本地Tavily预算耗尽或总时限到达时，重新使用智谱搜索并总结。在同一次MCP调用中返回备用结果。不再先返回Tavily答案再后台总结。

正常的“材料不足”回答不自动判为API故障；本实现不承诺识别所有不相关网页或事实错误。两套服务均失败时明确返回失败，不编造答案。

主链路总时限8秒，备用总时限12秒；外部调用等待预算约20秒，另有少量本地调度与缓存开销。小智端实际截止时间不由本服务控制，不能承诺语音端绝无超时。备用成功缓存最多复用60秒，之后重新尝试主服务；主用成功缓存沿用既有TTL。

Tavily请求在发送前预留本地额度；不对超时等计费不确定的失败退款，以免超过免费预算，所以本地计数可能高于真实扣费。智谱备用使用独立账户额度，不受Tavily免费预算限制，可能产生费用。
